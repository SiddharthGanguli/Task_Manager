# Simple Task Manager

A command-line based task manager built in Python. This lightweight tool allows you to add tasks with timestamps and view them in a readable format.

## Features

- Add multiple tasks
- Each task is timestamped with the time it was added
- View a list of all tasks in the session

## Requirements

- Python 3.6 or higher
